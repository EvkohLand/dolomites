# Historique des échanges e-mail — voyage Dolomites

Dernière consolidation : **29 septembre 2026**.

Ce dossier archive les échanges e-mail liés à la préparation du road trip dans les Dolomites : campings, agricampings, fermes, étapes de transit et Agricamper.

## Source et périmètre

Recherche effectuée dans les trois boîtes e-mail connectées :

- boîte personnelle principale : contient les échanges utiles ;
- seconde boîte personnelle : plusieurs messages reçus y apparaissent aussi en doublon/transfert ;
- boîte professionnelle : aucun échange Dolomites trouvé.

Période couverte : **11 septembre 2026 → 29 septembre 2026**.

Inventaire consolidé :
- **39 messages de correspondance voyage** retrouvés autour des demandes de camping/Dolomites ;
- **5 notifications Agricamper** antérieures directement liées au renouvellement ayant déclenché la demande ;
- les doublons entre boîtes ont été dédupliqués.

## Important — dépôt public

Le dépôt est public. L'archive conserve les faits, les dates, les objets, les prix, les conditions, les réponses et l'état des dossiers, mais n'expose pas :
- l'adresse Gmail personnelle ;
- les marqueurs techniques ChainMail ;
- les URLs d'offres personnalisées contenant des identifiants uniques ;
- les liens de renouvellement personnels.
